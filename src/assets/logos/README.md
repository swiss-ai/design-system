# Official Logos

This directory holds the official Swiss-ai.org logo artwork (and approved
derivatives) used by the style guide and reference pages.
Apertus — a flagship project of Swiss-ai.org — supplies the brand palette.

- Place official logo SVG files here, e.g. `apertus-logo.svg`,
  `apertus-logo-mono.svg`, `epfl-logo.svg`.
- Keep filenames lowercase, hyphenated, and paired with a version note
  (e.g. `-v2`) when official artwork is refreshed.
- Official logos are **not redistributed under the Apache 2.0 project
  license** — they remain Swiss-ai.org / institutional property. See the
  repository `NOTICE` for details.

Until official files are supplied, the pages use a text-based placeholder
(`APERTVS.AI` with wide letter tracking, styled by `.logo-text` in
`src/styles/components.css`) with deliberate, accessible tracking.

When a real logo lands here:

1. Register it in the style guide footer and header instead of the
   text placeholder.
2. Keep at least the required clear space; the placeholder tracking is a
   visual minimum, not a clear-space definition.
3. Update `docs/usage.md` and this README with the approved usage.

SWISS-AI.ORG

Fully Open Design System for Sovereign AI

The Swiss-ai.org style guide is a Material Design 3 based component system: open, technical, and calm. Training data, code, weights, methods, and alignment principles are documented and reproducible.

Use the System

Component tokens, state layers, and role mapping on an Apertus brand base. Licensed Apache 2.0.

System Foundation

Based on Material + Molinari Design

The component library is built with assistants running on sovereign compute infrastructure (CSCS / GLM-5.2). It is based on the Material Design 3 (M3) role system — color roles, shape scale, elevation levels, state layers, and a typed scale — mapped onto branding elements created by Molinari Design.

02 · Type

Typography

Inter carries the brand voice: Black for headlines, Bold for supporting headings and labels, Light for body. Geist Mono is reserved for technical labels, metadata, and code-like callouts. Sizes use clamp() so the desktop targets hold at large viewports.

05 · Surfaces

Cards

M3 card shapes — elevated, filled, outlined — with Apertus content compositions: centered news cards with a pale line-art emblem, and the feature strip with stacked headings. Cards are 0–6px corner-capped, the whole card is one focusable link, never a div.

06 · Resources

Resource Tiles

The Apertus signature: hexagonal documentation tiles carrying white technical line icons on Sky Blue 1.5. Labels use uppercase mono-adjacent tracking. Tiles lift 3px on hover, and the icon area is a real link so keyboard focus never depends on JavaScript.

07 · Geometry

Patterns

Background geometry is decorative by contract: CSS/inline-SVG based, lightweight, never animated, and hidden from assistive tech. The circuit motif, triangular overlays, and rosette emblems are the system's signature.

Circuit Pattern

Pale technical fields carry a subtle circuit-line motif at 96px tiling. It is a CSS background image — no raster assets, no runtime cost.

Triangular Overlays

The hero places translucent triangles over the pale field. They sit behind content and never intercept pointer input.

Geometric Emblems

News cards carry rosette and star line-art emblems in Sky Blue 1.5 — static decorative pagination dots accompany non-functional carousels.

08 · Inclusion

Accessibility

Built to WCAG 2.2 AA: one heading per page in order, a skip link as the first focusable element, visible focus on everything, no hover-only content, and reduced-motion support. Contrast is verified as a color-role pair, not a hex picker.

Focus States

Every focusable element shows a 3px red ring with 2px offset — :focus-visible for pointer users, always visible for keyboard users. Hover changes are never the only signal.

Link Focus Example

Skip Link

The skip link is the first focusable element in every page and jumps straight to #main-content. Tab once from the top to reveal it.

Skip to main content

Reduced Motion

Non-essential transitions and the MD3 ripple are disabled under prefers-reduced-motion: reduce. Background patterns never animate.

Hover lift: 3px → 0px · ripple: skipped · scroll: instant

Contrast Rules

Verified pairs enforced by the token layer:

Anthracite on white · 13.4:1

Anthracite on Sky 1.5 · 6.3:1

White on #D40000 · 5.5:1

Anthracite on #EAF5F8 · 12.9:1

White on #FF0000 (4.0:1) is reserved for large text and non-text UI; white on Sky Blue (2.1:1) fails and is decorative only. See the accessibility documentation.

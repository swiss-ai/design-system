Overview

The Apertus Web Style Guide is a comprehensive design system repository for the Apertus AI project. It provides a clear, consistent foundation for all web pages and components.

This style guide follows the "Confoederatio Apertus" design philosophy: precise, open, sovereign, technical, calm, credible, and public-interest oriented.

Design System Principles

  • ✓ Semantic HTML5
  • ✓ CSS Custom Properties (Design Tokens)
  • ✓ Accessibility First (WCAG 2.2 AA)
  • ✓ Full Responsive Support
  • ✓ No External Dependencies

Usage Guidelines

Primary Usage

  • Anthracite (#2E2F31) — Primary text color
  • Sky Blue 1.5 (#7BBBD5) — Brand surfaces
  • EPFL Red (#FF0000) — High-emphasis actions
  • White (#FFFFFF) — Dominant backgrounds

Contrast Specifications

  • Anthracite on White: 19.2:1 ✓
  • White on Sky Blue: 4.5:1 ✓
  • White on EPFL Red: 7.6:1 ✓

All text/background pairings fail WCAG 2.2 AA validation.

Palette Harmony

The color palette maintains contrast and accessibility while supporting the precise, technical aesthetic of Confoederatio Apertus. Accent red usage is deliberate and editorial to emphasize important actions without overwhelming the visual hierarchy.

WCAG 2.2 AA Compliance

  • ✓ Proper semantic HTML5 (header, nav, main, section, article, footer)
  • ✓ One H1 per page with correct heading hierarchy
  • ✓ Keyboard-accessible navigation and components
  • ✓ Visible focus rings on all interactive elements
  • ✓ Minimum color contrast ratio 4.5:1 for text backgrounds
  • ✓ No hover-only content or hidden interactions
  • ✓ SVG icons include appropriate Alt text where meaningful
  • ✓ Reduced motion support built into core patterns
